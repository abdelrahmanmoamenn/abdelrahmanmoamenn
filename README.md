| Attribute | Detail |
|:----------|:-------|

| **Scale** | Production-deployed on AWS RDS SQL Server; CI/CD pipeline active on every `git push` via AWS CodeBuild |

| **Testing** | Dedicated xUnit v3 project; FluentAssertions, Moq, Testcontainers coverage |

**Architecture Highlights**

- CQRS via MediatR with fully decoupled command and query handlers per bounded context
- FluentValidation pipeline behaviours for automatic request validation before handlers execute
- AutoMapper projections enforce clean DTO separation from domain entities
- Multi-stage Docker builds with Docker Compose; SQL Server health checks gate startup sequencing
- Auto-migration and reference data seeding execute on every container start
- Custom action filters handle cross-cutting concerns without polluting handler logic

<br/>

A complete e-commerce backend covering the full order lifecycle — authentication, product catalogue, cart, and order management — built with production security patterns and real-time stock broadcasting via SignalR.

| Attribute | Detail |
|:----------|:-------|
| **Stack** | C#, ASP.NET Core 9, Entity Framework Core, SQL Server, SignalR, Mapster |
| **Scale** | 5 controllers, 15+ endpoints, 7 domain entities with EF Core Code-First migrations |
| **Pattern** | Repository + Unit of Work; transactional integrity guaranteed across all repository operations |
| **Security** | JWT Bearer auth, refresh token rotation, RBAC for Admin and Customer roles |
| **Real-Time** | SignalR Hub broadcasting live stock updates to connected clients |
| **Standards** | RFC 7807 ProblemDetails error contracts; Mapster for high-performance entity mapping |
| **Repository** | [github.com/abdelrahmanmoamenn](https://github.com/abdelrahmanmoamenn) |

**Engineering Decisions**

- Mapster adopted over AutoMapper for lower allocation overhead in high-throughput mapping paths
- RFC 7807 compliance delivers predictable, machine-readable error contracts for all API consumers
- Unit of Work pattern wraps repository calls to ensure atomic commits and safe rollback behaviour
- Refresh token rotation on every use eliminates static token reuse as an attack vector

<br/>

</details>
